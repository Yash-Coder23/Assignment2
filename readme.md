##Task-Laundary Services Hero section.

##Description:
We built a Laundry Service website hero section using HTML and CSS.

Navbar:
Logo on left, nav links in middle, username on right

Used float and display: inline.

Hero Section:
Left side has heading, description and a button

Right side has a laundry image

Used vh and vw units so page fits in screen without scrolling

Two divs placed side by side using display: inline-block.

How to Run:
Open the project folder in VS Code

Right click on index.html

Click "Open with Live Server"

It will automatically open in your browser.
